# Self-Healing RAG — Phase 1 Baseline

Phase 1 provides a small, controlled baseline RAG pipeline designed to run in
Google Colab using only local, open-source models. It performs dense retrieval
with SentenceTransformers and FAISS, then generates a grounded answer with
Qwen. Self-healing and other advanced retrieval features are deliberately out
of scope for this phase.

Open `notebooks/01_baseline_rag.ipynb` in Google Colab for the complete demo.
